# TVS RiDE-Aero 2.0 Interactive Simulator
### Rider-Adaptive, Speed-Aware Kinematic Windscreen System for TVS Apache RR 310

Live interactive engineering simulation for TVS Rideideathon 2026.

## Live Simulation
Access the live simulator: [https://chaitanyaprasad-ece.github.io/ride-aero-simulator-/](https://chaitanyaprasad-ece.github.io/ride-aero-simulator-/)

## Features
- **Dynamic 2D Kinematic & Airflow CFD Canvas**: Real-time 4-bar linkage positioning and stagnation/wake stream visualization.
- **AI Vision Perception Viewport**: Simulated 28.4 FPS YOLOv8 pose and helmet detection.
- **Adaptive CAN Speed & Ergonomic Stature Sliders**: Test across 0–140 km/h vehicle speed and 160–188 cm rider stature.
- **Track Crouch (Sport Tuck Mode)**: Quick aerodynamic posture test.
- **Pure Zero-Dependency Architecture**: Standalone HTML5 + Tailwind CSS + Canvas.
